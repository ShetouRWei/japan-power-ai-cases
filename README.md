# 日本電力公司 AI 案例庫

日本主要電力集團的 AI 與數位轉型案例瀏覽網站。

公開網站：<https://shetourwei.github.io/japan-power-ai-cases/>

## 更新資料

1. 更新上一層的 `日本電力公司AI案例庫.md`。
2. 在 Windows 執行 `更新網站資料.cmd`，重新產生 `cases-data.js`。
3. 提交並推送變更，GitHub Pages 會自動發布。

## 算力部署欄位（v1.13）

每案必填「算力部署」「部署判定說明」「部署查核來源」，部署分類為地端、雲端、混合部署或未揭露。建置時會檢查欄位完整性。網站提供卡片標籤、部署篩選及全文搜尋。

部署分類的範圍與逐案來源見 [2026-11-24查核彙整](deployment-audit-2026-11-24.md)。僅有API、資料上雲、產品可支援選項或閉域連線時，不直接推定AI運算位置。
